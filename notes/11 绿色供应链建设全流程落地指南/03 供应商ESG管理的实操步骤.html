🏭 03 供应商ESG管理的实操步骤

全流程五步法：准入门槛 → 行为规范 → 绩效评估 → 能力建设 → 激励与退出（基于原教材第21-80页）

1️⃣ 设定ESG准入门槛

  • 目的：从源头筛选合作伙伴，降低声誉、财务与运营风险。
  • 核心活动：资质审查 → 签署承诺 → 初步评估 → 采购评审 → 合同嵌入ESG条款。

📋 1.1 资质审查

  • 要求供应商具备关键体系认证，常见基础认证包括：
    • ISO 9001（质量管理体系）
    • ISO 14001（环境管理体系）
    • ISO 45001（职业健康安全管理体系）
  • 根据行业与企业风险特征，还可要求以下相关ISO标准：
    • ISO 27001（信息安全管理体系）
    • ISO 37001（反贿赂管理体系）
    • ISO 26000（社会责任指南，非认证性标准但可作为参考）
    • ISO 50001（能源管理体系）
    • ISO 14064（温室气体排放核算与核查）
    • ISO 20400（可持续采购指南）
    • ISO 28000（供应链安全管理体系）
    • ISO 37301（合规管理体系）
    • ISO 31000（风险管理体系，非认证性指南）
  • 通威股份案例：在筛选准入环节明确考虑ISO 9001、ISO 14001、ISO 45001等认证，并实施供应商分类管理。
  • 资质审查是供应商导入的前置条件，只有通过基本认证的企业方可进入“合格供应商”名单。

📝 1.2 签署承诺

  • 要求供应商签署《廉洁承诺书》《无冲突矿产承诺书》等，将ESG要求延伸至整个供应链。
  • 案例：安踏体育要求签署《诚信廉洁协议》；某电子企业《供应商商业廉洁准则》（含违约责任：全球营业额3倍或不当利益20倍罚款）。
  • 通威股份：签署《供应商合规承诺函》《冲突矿产声明与承诺》，并要求100%签订率。

📊 1.3 初步评估（供应商调查问卷）

  • 基础信息：公司规模、销售额、员工数量、生产地址等。
  • ESG相关提问：是否提供产品碳足迹？是否优化可持续包装？是否使用可再生能源？是否有环境政策？
  • 示例：某机械企业问卷中包含碳足迹、回收、节能生产方法等问题。

⚖️ 1.4 采购评审加入ESG条件

  • 作为加分项：为供应商ESG表现额外加分。
  • 作为定标条款：专家评审总分、技术分、报价分相同时，ESG表现更优者中标。
  • 案例：北京市公共资源交易中心在51个政务云项目中设置ESG定标条款。

📄 1.5 采购合同嵌入ESG条款

  • 中金公司：2023年在采购合同模板中加入可持续采购条款，要求遵守环境、安全健康、社会责任、商业诚信等法律法规。
  • 某化工巨头：合同明确要求遵守《供应商行为准则》，并对人权尽职调查作出规定，参照德国《供应链尽职调查法》。
📌 重点 准入门槛的关键是“资质+承诺+评估+合同”四层过滤，缺一不可。尤其合同条款需包含整改义务和退出权利。

2️⃣ 规范供应商行为

  • 2.1 制定供应商行为准则：企业应制定明确的供应商行为准则，确立在环境、劳工权益及商业道德等方面的核心要求与行为底线，并将其作为对供应商具有约束力的合作基础。
  • 2.2 供应商行为评估：为确保准则有效落地，企业需建立常态化的评估机制，通过文件审查与现场审核等方式，验证供应商的合规表现，并推动其持续改进。

📜 2.1 制定供应商行为准则

  • 华为供应商社会责任行为准则：参照《责任商业联盟行为准则》（RBA准则）和《全球电信企业社会责任联盟供应链可持续指南》（JAC指南），要求供应商遵守经营所在国家/地区的所有适用法律法规，华为有权对供应商的现场进行合理通知下的审核。
  • 通威股份有限公司供应商行为准则：涵盖商业道德、人权劳工、环境保护、安全健康等方面，要求供应商遵守运营所在地法律法规，鼓励持续加强可持续发展管理。
  • Apple供应商行为准则：包含劳动权益与人权（20项）、环境（9项）、道德（9项）、管理体系（8项）四大原则，要求供应商提供安全、尊重尊严的工作环境，并采取对环境负责的行为。
  • 行业关键ESG议题识别：纺织业重点关注劳工人权，电子/汽车行业关注冲突矿产。

🔍 2.2 供应商行为评估

  • 评估方法：管理层访谈、文件审查、员工访谈（无管理层在场/无监控）、实地检查、独立第三方评估。
  • 苹果公司供应商行为评估实践：
    • 每年进行《行为准则》评估，根据500多项指标对供应商进行综合评估，由经认证的独立第三方审计公司进行。
    • 2023年报告期内进行了893次独立的第三方评估。
    • 通过保密访谈和匿名调查直接收集供应商员工意见。
    • 定期进行突击评估和访问（2023年全球203次突击评估），调查员工提出的顾虑并验证风险。
    • 可再生能源审计：验证供应商用电量、碳足迹计算方法及可再生能源采购文件（2023年6个国家地区94次审核）。
    • 废弃物零填埋数据审核：与UL合作，新增评估方式验证供应商废弃物数据。
    • 回收商审核：2023年评估98个回收点，核实遵守准则和标准。
    • 以问题为中心的审核：根据地理位置、评估历史、材料使用等因素选择供应商进行重点审核（2023年153次）。
💡 关键点：行为准则须公开发布并纳入合同，评估需常态化，突击检查能有效防止“纸面合规”。

3️⃣ 供应商绩效评估

📈 3.1 内部评估

  • 传统指标：质量、交付、成本、服务。
  • 融入ESG指标：环境影响度（废气/废水/固废）、能源消耗度、资源回收率等。
  • 隆基绿能：按月度/半年度考核，结果分为A/B/C三级，对应奖惩。
  • 《供应商ESG评价指南》（T/CERDS17—2025）：6个评价议题、7个评价维度，结果一星至七星（分数区间0-200分）。

🌍 3.2 外部评估平台

  • EcoVadis：评估环境、劳动与人权、商业道德、可持续采购四个领域，通过政策、行动、结果、360°观察等管理指标评分。
  • SMETA：Sedex推出的审核，涵盖劳工标准、健康安全、环境、商业道德，出具纠正行动计划报告。
  • RBA VAP/SVAP：独立第三方现场验证，专用于强迫劳动风险识别。
  • CDP：气候变化、水、森林披露，联想要求主要供应商填报，2024年回复率98%。
  • 应用案例：欧莱雅965家供应商接受EcoVadis评估；Coca-Cola HBC要求第三方审计（SMETA+EcoVadis）；DELL要求供应商通过RBA认证审计员审核。

4️⃣ 供应商ESG能力建设

  • 常见方式：培训教育、技术支持（绿色技术/工艺优化）、资金支持（绿色贷款/资助）、供应商支持平台、建立合作伙伴关系。
  • 隆基绿能：2024-2028年CSR能力建设计划，目标覆盖核心供应商采购金额80%（2025-2028）。
  • 台积电：设立“供应商永续学院”，提供90门课程（安全、劳动人权、环境保护等），累计使用310万人次；开发“供应商环境信息数字平台”简化数据填报。
  • H&M与星展银行：绿色贷款计划，支持印度供应商Raj Woollen安装太阳能、节能电机和水资源保护技术。
📌 能力建设是企业长期投入，有助于建立稳定、负责任的供应链，尤其需要关注中小供应商的资源局限。

5️⃣ 供应商的激励与退出

🏆 正向激励方式

激励方式说明 延长合作期限增强供应商业务稳定性 增加合作份额提高供应商营业额与获利能力 增加物品类别降低一次性送货成本 供应商级别提升增强美誉度和市场影响力 书面表扬/证书/锦旗提升供应商声誉 现金或实物奖励直接经济激励

⚠️ 负向激励（约束措施）

负激励方式具体做法
缩短合作期限减少长期协议保障
减少合作份额降低采购金额
减少物品类别缩小合作范围
业务扣款违约或不合规罚款
降低供应商级别限制新项目参与资格

🚪 退出机制

  • 隆基绿能：淘汰（限制参与新采购，一年内不复用）与黑名单（集团范围内永不复用）。
  • 通威股份：停止采购或取消合格资格，严重违规列入黑名单永久取消合作。
  • 案例：某电子产品企业2024年有6家供应商因ESG绩效优异获得更多订单，未出现符合淘汰条件的供应商。
🧠 重难点辨析
• 激励与退出必须基于透明的ESG绩效评分，避免主观判断。
• 退出是“最后手段”，应先给予整改机会和能力支持，严重违规或拒绝整改方可淘汰。
• 正向激励不应仅看ESG绝对分数，更要关注改善幅度和长期承诺。
• 多个法规（如德国LkSG、欧盟CSDDD）要求企业建立申诉机制及补救措施，退出前必须穷尽合理努力。
