🔍 04 供应链尽职调查的全流程指南

基于OECD六步法 · 覆盖CSDDD/LkSG/冲突矿产法规 · 完整实操框架（原教材第81-189页）

1️⃣ 明确尽职调查核心原则

📌 1.1 什么是供应链尽职调查

  • 定义：企业为识别、预防、减缓或终止其供应链中可能发生的负面人权影响、环境影响及其他可持续发展风险，而开展的一系列制度化流程与管理活动。
  • 来源：OECD政策体系（2011年起），也是欧盟CSDDD、德国LkSG、法国警惕义务法等立法的蓝本。

⚠️ 1.2 为什么要开展供应链尽职调查

  • 拉纳广场事件（2013孟加拉）：1134人死亡，推动全球供应链尽责立法。
  • 刚果钴矿童工：约4万名儿童在危险环境采矿，成为冲突矿产法规的重要现实依据。

📜 1.3 供应链尽调法规（演变与对比）

  • 欧盟CSDDD（2024生效）：要求建立尽调体系，识别人权/环境风险，预防缓解，监测披露，申诉机制，民事赔偿责任（最高罚金全球净营业额5%）。
  • 德国LkSG（2023起）：分阶段实施（雇员≥3000→≥1000），建立风险管理体系、人权官员、投诉机制、年度报告。
  • 法国警惕义务法（2017）：要求制定并公布警觉计划。
  • 欧盟冲突矿产条例：针对3TG（锡、钽、钨、金）进口商，须按OECD指南实施尽调。
  • 欧盟新电池法规：电池关键原料（钴、锂、镍等）尽调义务，需符合OECD指南。
  • 国内相关法规：《劳动法》《公司法》《数据安全法》《反外国制裁法》《中国负责任矿产供应链尽责管理指南》等。
📌 重点 CSDDD 不仅适用于欧盟企业，也影响在欧营业额超过4.5亿欧元的非欧盟企业及其供应链中的中国企业。

📋 CSDDD框架下的企业义务（条款号摘要）

2️⃣ 搭建尽职调查框架和流程

🌐 OECD《负责任商业行为尽职调查指南》—— 全球基准六步法

  1. 将负责任商业行为融入政策与管理体系
  2. 识别与评估运营、供应链和业务关系中的不利影响
  3. 终止、防范或减轻不利影响
  4. 跟踪实施情况与结果
  5. 沟通如何消除影响
  6. 适时提供条件或开展合作进行补救

🇩🇪 德国LKSG尽调流程

  • 建立风险管理体系 → 指定人权官员 → 制定政策声明 → 开展风险分析 → 预防措施 → 补救措施 → 投诉机制 → 记录与报告（年度报告提交BAFA）。
  • 宝马、博世等企业已按LKSG要求发布尽调报告，博世识别15种高风险原料（锡、锂、钴、天然橡胶等）。

⚔️ 冲突矿产尽调流程（基于OECD冲突矿产指南）

  • 五步法：筛选供应商位置 → 定方案 → 执行尽调 → 评结果 → 定计划。
  • 高通、新普公司案例：使用CMRT模板，遵循OECD五步法，参与RMI并公开冲突矿产报告。

3️⃣ 将负责任商业行为融入政策与管理体系

八大核心要素

  • 政策承诺、治理与责任分配、程序与工作流程、资源与能力建设、数据系统与信息流、合同与商业条款、申诉/举报机制、监控与持续改进。

📄 起草《尽职调查政策与承诺》

  • 内容须涵盖范围、对OECD/UNGP/ILO的承诺、“停止/减缓/补救”原则、利益相关方权利。

🏛️ 内嵌组织与RACI矩阵

  • 设立跨部门尽调委员会（采购、法务、ESG、HR、EHS等），明确负责人、担责人、参谋、汇报对象。
  • 将尽调嵌入供应商生命周期管理（SLM），并在合同中加入“尽调配合、整改义务”条款。

📊 设定KPI与监控指标

  • 示例：Tier1供应商问卷覆盖率≥95%，可追溯采购量≥50%，高风险供应商整改完成率≥90%，申诉60天内闭环率>90%。

4️⃣ 识别和评估运营、供应链和业务关系中的不利影响

🔎 4.1 界定范围，识别风险领域

  • 风险类别：行业风险、产品风险、地理风险、企业层面风险。
  • 三层识别：自身运营（如汽车行业：加班超时、化学品暴露）、上游供应链（钴矿强迫劳动、冲突矿产）、下游（运输碳排放、电池回收）。

📋 4.2 设置风险识别清单（Checklist）

  • 参考国际标准：OECD指南、UNGPs、ILO公约、ISO 20400、GRI、SASB、ESRS、EcoVadis、CDP等。

📁 4.3 资料与信息收集

  • 一手资料：供应商自评问卷（SAQ）、审计报告、员工访谈、现场检查、合同许可证等。
  • 二手资料：学术研究、NGO报告、政府数据、行业指数等。
  • 核验维度：真实性（证书验证）、有效期、一致性、完整性、来源可靠性分级（一级：政府/独立审计；二级：供应商文件；三级：新闻/NGO报告需佐证）。

📐 4.4 风险评估与分级

风险值公式：风险值 = 严重性 × 可能性 × 可控性
评分范围：严重性1-5，可能性1-5，可控性0.1-1
风险等级分值区间（示例）
高风险≥16
中风险8-15
低风险≤7

🌍 4.5 大众负责任供应链系统（ReSC）

  • 大众集团每年披露高风险供应链缓解措施，建立风险分级矩阵。

⛏️ 4.6 欧盟冲突矿产条例下对上游供应商尽调

  • 适用矿物：3TG（锡、钽、钨、金），地域：冲突影响和高风险地区（CAHRA）。
  • 使用CMRT/EMRT模板收集冶炼厂信息，与CAHRA名单对比，核对RMI“负责任冶炼厂白名单”。
  • 评估供应商尽调体系：政策承诺、管理系统、风险识别与应对（闭环流程）。

5️⃣ 终止、防范或减轻不利影响

📌 5.1 制定风险处置决策

第一步：明确企业与不利影响的关系类型

  • 造成（Cause）：企业自身行动直接导致（如BP墨西哥湾漏油）。→ 必须立即终止+补救。
  • 促成（Contribute）：企业行为不是主因，但共同形成因果链（如H&M低价短交期导致供应商超时加班）。→ 改正自身行为+联合整改。
  • 直接关联（Directly Linked）：不利影响与企业产品/业务挂钩，但非企业造成或促成（如雀巢可可供应链童工）。→ 施加影响力、行业协作。

只有在造成/促成时，OECD才允许“立即终止业务”作为优先选项。

第二步：根据风险严重性做出行动决策

严重性级别举例行动
重大 (Severe)强迫劳动、童工、严重环境破坏立即停止+调查+公开报告
中度 (Moderate)法规违规、重大职业安全隐患启动CAP（纠正行动计划）
轻度 (Minor)文件缺失、管理不足日常整改与跟踪

📋 5.2 制定并实施“终止/预防/减轻”的行动计划

🔴 情形一：企业“造成”（Cause）不利影响 → 必须立即终止+补救

  • 动作1：立即停止相关活动（如停止使用非法劳工、停止向不合规排污设施排放、停止非法采矿活动的采购）。
  • 动作2：实施补救措施（支付补偿、保障受害者权益、停止违法劳务派遣、启动环境修复）。
  • 动作3：修正内部制度（修订操作规程、培训员工、增设内部审核机制）。

🟠 情形二：企业“促成”（Contribute）不利影响 → 立即改正+与供应商共同整改

  • 动作4：止损行动（如调整过短交付周期、调整价格策略避免供应商偷工减料）。
  • 动作5：制定联合整改计划（与供应商共同完成根本原因分析RCA，制定纠正与预防行动）。
  • 动作6：提供能力建设支持（ESG/人权/EHS培训、提供管理制度模板与工具、废水处理技改等技术支持）。

🟢 情形三：企业“直接关联”（Linked）不利影响 → 施加影响力+分级处理

  • 动作7：施加商业影响力（合同约束供应商行为准则、审核权条款、采购激励/扣分机制、战略合作优先采购）。
  • 动作8：提升透明度与追溯（要求披露Tier-1/2名单，使用CMRT/EMRT追溯系统，定期报告进展）。
  • 动作9：行业协作（加入RMI矿产倡议、Drive Sustainability汽车平台、EPRM等多方行动平台）。

📝 5.3 执行整改计划与监控（CAP）

  • CAP必须包含：问题描述、根本原因（5 Why）、纠正措施、预防措施、责任人、时间表、验证方式。
  • 亚马逊供应商标准手册：整改以员工为核心，CAP需20个工作日内返回，严重问题可暂停生产/采购，拒绝整改可终止关系。
📌 亚马逊核心原则 任何整改工作都应该以员工为核心。将受影响员工的安全和利益放在首位。整改计划需包含根本原因说明、即时纠正措施、长期预防措施、责任人及完成日期。

🚪 5.4 无法改善时的脱离

  • 适用情形：严重人权侵害、欺骗伪造、拒绝整改、故意违法、不改善将造成重大危害。
  • 执行：移入黑名单/限制名单。

6️⃣ 跟踪实施情况与结果

📊 6.1 建立风险与整改跟踪台账

  • 按风险等级设置跟踪周期，记录CAP完成度、验证方式、下次跟踪时间、负责人。
  • 示例：昆明机场环境与社会行动计划表（含组织能力、环境管理、社会指标）。

✅ 6.2 验证整改结果（实质性改善三层面）

  • 制度改变：新制度/流程出台。
  • 实践改变：现场行为真正变化。
  • 结果改善：风险水平下降，事故/投诉减少。
  • 方法：根因分析（5Why、鱼骨图）、纠正→预防措施、量化KPI（基线→目标）、多源验证（文件+现场+员工访谈）。

🚀 推动实质性改善（从“症状整改”升级为“深度改善”）

  • 方法一：从“症状整改”升级为“根因整改”
    要求供应商使用5Why分析（连续追问“为什么”直到找到根本原因）或鱼骨图（从“人、机、料、法、环、测”等维度分析），避免只解决表面问题。
  • 方法二：把纠正措施升级为预防措施
    CAP中至少分两类措施：
    - 纠正措施（解决当前问题）：补发加班费、清理违规库存化学品、安装防护装置等。
    - 预防措施（防止再发生）：修改排班与审批制度、建立化学品采购审批流程、将EHS表现纳入班组长绩效等。
  • 方法三：用“量化指标+基线数据”衡量改善效果
    为每个重大整改点设置KPI，记录基线值（整改前）与目标值。例如：加班超36h/月员工比例从60%降至10%；职业伤害年均从10起降至3起以内。
  • 方法四：使用“多源验证”确认整改成效
    至少包括两项以上验证方式：文件验证（工时记录、检测报告）、现场验证（生产现场、仓库、污水站）、员工访谈（是否真正减少加班、获得防护用品等）。三者一致才视为真正改善。
💡 典型实践：Apple禁止供应商向工人收取“招聘费”，并通过审计+整改+经济责任转移，2008年以来已退还近2100万美元，覆盖超3万名工人。

🏆 6.3 驱动供应商持续改善

  • 正向激励：优先供货、延长合同、公开表扬。
  • 负向约束：降级、减少订单、高风险观察。
  • 纳入评分体系：QCD（质量、成本、交付）权重+ESG评分（建议30%权重）。
  • 典型案例：Nike供应商阶梯机制（黄/红牌，金牌供应商获优先权）；Apple禁止招聘费并强制退款（2008年以来退还近2100万美元）。

🔄 6.4 持续优化制度与策略

  • 将跟踪结果与管理层薪酬/部门绩效挂钩，定期召开供应链风险复审会议。

7️⃣ 沟通如何消除影响

💡 核心原则：企业必须向利益相关方（客户、投资人、监管层、公众）透明地说明：识别到哪些风险？采取了哪些行动？取得了哪些效果？

💬 对内与对外沟通

  • 对内：月报/季报、部门会议、内网。
  • 对外：公司官网、社交媒体、尽调报告、ESG报告。

📢 建立供应链申诉与举报通道

  • 对标OECD与UNGP：匿名、多语种、24-48h响应、专人跟踪闭环。
  • 案例：ADM申诉邮箱、上海杉杉申诉与沟通机制。

📄 在报告中正式披露

  • ESG/CSR报告中加入《尽职调查章节》，包括治理架构、风险识别方法、评估结果、整改措施、改善效果等。
  • CSDDD要求每年公开发布专项尽调报告（10项内容）。

8️⃣ 适时提供条件或开展合作进行补救

  • 补救是独立关键过程，不限于尽责管理组成。提供补救不是尽责管理的组成部分，而是企业应该提供条件并支持的一个单独、关键的过程。
  • 建立补救机制：企业应建立清晰、可及、透明的内部补救流程，明确责任部门和处置时限，为受不利影响的个人或社区提供有效补救渠道（如赔偿、医疗、恢复工作、制度改善等），并与申诉机制联动，确保受害者能够安全、便捷地提出诉求。
  • 专项调查与整改：针对已发生的严重不利影响，企业应启动专项调查，查明根本原因、影响范围和责任归属，并制定专项整改计划（含短期纠正措施和长期预防措施），防止类似事件再次发生。必要时聘请独立第三方参与调查和评估。
  • Primark案例：Rana Plaza倒塌后，Primark提供短期经济支持，并设立长期补偿计划（约1100万美元，与国际劳工组织合作），额外追加捐款和金融教育。

📌 本节重难点归纳

✅ 重点
• OECD六步法是全球尽职调查的通用框架，所有法规均参考或直接引用。
• 风险值公式（严重性×可能性×可控性）是分级管理的定量基础。
• 企业必须区分“造成/促成/直接关联”三种关系类型，采取差异化行动（终止 vs 联合整改 vs 施加影响力）。
• 整改有效性需验证“制度-实践-结果”三层实质性改善，而非仅纸面CAP。
• CSDDD要求建立申诉机制和民事赔偿责任，处罚可达全球净营业额5%。
• 冲突矿产尽调须使用CMRT/EMRT模板，并核对RMI白名单/CAHRA名单。
🧠 难点/易混淆
• 尽职调查 ≠ 一次性审核，而是持续循环的“政策→识别→行动→跟踪→沟通→补救”闭环。
• “补救”与“整改”的区别：整改（CAP）是预防未来风险，补救是针对已发生的损害提供赔偿/恢复。
• 许多企业误以为只要一级供应商签署承诺书即可，但法规要求穿透至高风险二级/三级供应商（如矿产冶炼厂）。
• 风险评估中的“可控性”指数（0.1-1）需要根据企业对供应商的影响力（采购份额、合同约束力）动态调整。
• 欧盟CSDDD与德国LkSG的差异：CSDDD涵盖下游（分销、仓储），LkSG更侧重上游；CSDDD有明确民事赔偿责任，LkSG由监管机构执法。
💡 尽职调查不是孤立项目，而是与供应商ESG管理（准入门槛、绩效评估、能力建设、激励退出）深度融合的全流程机制。
