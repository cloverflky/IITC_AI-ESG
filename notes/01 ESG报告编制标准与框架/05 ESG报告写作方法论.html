📘 ESG报告写作方法论 · 专题框架

基于〈05 ESG报告撰写全流程〉· 品职教育 · 王雪菲
📌 六大核心步骤 全流程

① 项目前期准备

  • 明确报告目的
  • 熟悉报告结构
  • 建立报告小组
  • 制定时间计划表

② 建立指标体系

  • 确定编制依据
  • 指标融合
  • 对标研究
  • 实质性议题分析

③ 报告资料收集

  • 访谈型 / 清单型
  • 定性+定量资料
  • 启动培训会

④ 报告大纲制作

  • MECE原理
  • ESG型 / 自由型
  • 语言润色
  • 专题聚焦

⑤ 报告正文写作

  • 资料整理
  • 致辞+正文+案例
  • 绩效数据
  • 指标索引

⑥ 报告设计与发布

  • 设计确认
  • 校对审核
  • 印刷传播
  • 总结复盘
① 项目前期准备 启动阶段

🎯 明确报告目的

  • • 强化品牌形象
  • • 提升ESG评级
  • • 吸引ESG投资
  • • 驱动内部管理

📋 熟悉报告结构

四大板块：前言 · ESG管理 · ESG实践 · 附录

报告说明含：时间范围、主体、数据来源、编制依据、保证等

👥 报告小组

  • • 管理层（最高责任）
  • • 牵头部门（执行主体）
  • • 各职能部门/子公司（资料提供）
  • • 外部专业机构（支持）

⏳ 时间计划表

需涵盖：启动会、资料收集、大纲撰写、初稿、修改、设计、定稿、发布等关键节点。

★ 重难点： 报告目的与受众定位 · 小组组建模式（核心团队/部门分工） · 时间计划表的可行性
② 建立指标体系 核心骨架

📌 确定编制依据

强制标准 + 综合标准 + 专项标准 （合规性、全面性、适用性）

🔗 指标融合四步骤

  • 1. 选择基础指标（强制性或最常用）
  • 2. 与其他参考指标对比，找差异
  • 3. 补充需融合的指标
  • 4. 适用性调整（含ESG评级指标）

📊 对标研究

  • • 行业标杆 / 同规模企业
  • • ESG评级更好 / 下游客户
  • • 看广度（指标全面性）& 深度（诠释程度）
  • • 关注特殊板块与设计风格

🧩 实质性议题分析

识别 → 评估（影响重要性+财务重要性）→ 确定（矩阵图/列表法）

★ 重难点： 双重重要性（影响+财务）· 利益相关方沟通 · 矩阵图绘制 · 议题清单调整逻辑
📐 最终指标体系 = 参考标准1 + 参考标准n – 重复指标 + 对标调整 + 突出实质性议题
③ 报告资料收集 素材基础

🎙️ 访谈型

将指标转为问题，通过访谈收集

  • • 适用：ESG起步期
  • • 挑战：耗时、对访谈者要求高

📋 清单型

设计问卷/清单，部门直接提交

  • • 适用：ESG成熟期
  • • 挑战：缺乏深度、部门应付

📦 资料类型

定性资料（理念、政策、举措、案例） + 定量数据（绩效指标）

存量资料（年报、制度等）+ 新资料（根据清单汇总）

📢 启动培训会

目的：统一认知，明确配合要求。参与：分管领导、牵头部门、各部门负责人及对接人。

★ 重难点： 访谈提纲设计 · 资料清单的完整性与可操作性 · 培训会内容设计
④ 报告大纲制作 结构设计

🧠 MECE原理

相互独立（不重复） + 完全穷尽（不遗漏）

📐 ESG型

按环境、社会、治理三大维度划分篇章，排序灵活

🎨 自由型

关键议题型 / 相关方型 / 上下篇型 / 其他

✍️ 大纲语言润色

  • • 对仗工整（一二级标题对仗）
  • • 叙事风格（科技感、正向、自由）
  • • 融入企业基因（行业特色、企业文化）

⭐ 特殊章节：专题聚焦

体现政治高度、年度大事、议题亮点

★ 重难点： MECE原则应用 · 自由型框架选择（亮点突出+章节平衡） · 标题润色与企业特色融合
⑤ 报告正文写作 内容填充

📝 致辞

结构：开头（时代背景+主责主业）→ 中间（ESG落实维度）→ 结尾（展望）

原则：有高度、有亮点、有呼应

📄 正文结构

理念 → 管理 → 实践 → 绩效 → 案例 （四要素法适用于高重要性议题：治理·战略·风险管理·指标与目标）

📊 绩效数据

  • • 数据验证：交叉验证 + 穿行测试
  • • 关键绩效表（环境、能源、安全、员工流动等）

📎 附录

  • • 指标索引（交易所/GRI/SASB等）
  • • 意见反馈表
  • • 关键绩效表

⚠️ 注意事项

  • • 批注来源 · 表达主体清晰 · 称谓规范 · 时间精准
  • • 表格标题在上，图片标题在下 · 数字千分符 · 小数位统一
  • • 无资料情况需说明（如气候风险分析）
★ 重难点： 四要素结构（治理·战略·风险管理·指标与目标）· 绩效数据验证 · 指标索引编制 · 案例撰写
⑥ 报告设计与发布 呈现与传播

🎨 设计确认

风格选择（科技/简约/插画等）

🔍 校对自查

  • • 整体：段落、标题层级、图片、数字统一
  • • 细节：文字、标点、专有名词、句子通顺
  • • 角落：页眉页脚、图注、图表、链接

📤 发布与传播

  • • 渠道：法定披露 + 主动宣传
  • • 形式：电子版、印刷版、长图
  • • 印刷：环保纸张、克数、装订、工艺

🔄 总结复盘

梳理不足与提升要点 · 回应外部利益相关方关切

★ 重难点： 设计风格与品牌一致性 · 校对细节（数据/格式/链接） · 印刷工艺选择
⛰️ 整体重难点 · 聚焦 指标体系融合（基础指标+差异补充） 实质性议题双重重要性评估 MECE大纲结构设计 四要素正文写作（治理·战略·风险管理·指标） 数据验证（交叉验证+穿行测试）
📌 关键公式：
百万工时损失工时率 = 因工伤损失工作日数 ÷ 总工时 × 1,000,000
指标体系 = 参考标准1 + 参考标准n – 重复指标 + 对标调整 + 实质性议题突出
